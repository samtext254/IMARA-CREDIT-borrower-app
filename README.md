# imara-onlineservice

Standalone borrower-facing web app for **IMARA CREDIT**.

## Status
Files scaffolded. Dependencies not yet installed.

## When ready to run
    cd C:\Project\imara-onlineservice
    pnpm install
    pnpm dev
    # open http://localhost:3002

## Backend dependencies
- AUTH_API_URL    -> XecoFlow auth-engine (default http://localhost:3001)
- LENDING_API_URL -> credit-service-engine client routes (default http://localhost:4099)
